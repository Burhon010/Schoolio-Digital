# Fonts

The design uses **Museo Sans** (weights 300, 500, 700, 900). It is a licensed
font — not bundled. Drop these files here and `src/index.css` picks them up:

- `MuseoSans-300.woff2`
- `MuseoSans-500.woff2`
- `MuseoSans-700.woff2`
- `MuseoSans-900.woff2`

Until then the fallback stack renders: Avenir Next → Century Gothic → system-ui.
